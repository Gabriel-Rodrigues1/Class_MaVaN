# Modified CLASS Code and Cosmological Analysis

This repository contains the **modified CLASS code**, **Cobaya configuration files**, and **analysis scripts** used to obtain the results presented in the paper "Effective Neutrino Mass and Apparent Phantom Crossing" **arXiv:** `[2610.10195](https://arxiv.org/abs/2610.10195)` .

The repository is intended to provide the numerical implementation and analysis pipeline necessary to reproduce the main results of the work.

## Contents

The repository includes:

- Modified **CLASS** source code implementing the cosmological model studied in the paper.
- **Cobaya** configuration files used for cosmological parameter estimation.
- Python scripts and Jupyter notebooks used for post-processing, statistical analysis, and figure generation.
- Additional configuration and input files required to reproduce the numerical calculations.


## Software

This work makes use of:

- [CLASS](https://lesgourg.github.io/class_public/class.html) — Cosmic Linear Anisotropy Solving System
- [Cobaya](https://cobaya.readthedocs.io/) — Bayesian analysis framework for cosmology
